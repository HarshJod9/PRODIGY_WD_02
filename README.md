# PRODIGY_WD_02 — Stopwatch Web Application

A focused, responsive stopwatch built with HTML, CSS and JavaScript.

## Run

Open `index.html` in a browser. No build step or dependencies are required.

## Features

- Start, pause, resume and reset
- Lap splits and cumulative times, newest lap first
- Hundredth-second display driven by `requestAnimationFrame`
- Keyboard shortcut: press Space outside a control to start or pause
- Optional sound cues, status indicator and accessible timer label
- Responsive layout with reduced external dependencies
